# 资料维护自动化

学习采用按需模式：不提供每日测试、周期复习、每周回顾、自动综合测验或学习配额。初始化时不主动推荐或创建这些任务。

## 可选资料摄取

只在用户明确要求时安排资料摄取或来源维护，沿用用户指定的范围与时间。遵循 [agent-compatibility.md](agent-compatibility.md) 中当前 agent 的机制。已有暂停任务不得自行启用。

- 扫描 active 课程 inbox，与 source manifest 的 SHA-256 去重。
- 按课程配置检查新资料和明确的 deadline 变更。
- 遵循 ingest / reading workflows，整理完整讲义草稿、候选题、来源与派生索引。
- 可以生成供日后主动使用的题库，但不发起测验，不安排未来复习，不生成日报或周报。
- 无变化时静默。原始文件不可修改；有争议的来源或 verified deadline 变更写 proposal。
- 在一次资料更新后验证结构、重建必要的 Overview；不要因为执行维护就要求用户学习或回答问题。
- 失败后报告一次并停止，不无限重试。

## 手动维护

用户可以随时请求检查知识库、重建总览或核验来源；不需要绑定固定周期。
